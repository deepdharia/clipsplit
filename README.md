# ClipSplit — Free Online Video Splitter

Turn long videos into Shorts / Reels / TikTok clips. 100% on-device, no uploads, zero server cost.

- **Fast path:** lossless stream-copy splitting (no re-encode)
- **Studio path:** 9:16 vertical / 1:1 square / blur background via hardware-accelerated WebCodecs
- One-tap Shorts presets (15/30/60/90s), custom cut points on a visual timeline, batch ZIP download

Static site — deploy the folder as-is to Vercel or Cloudflare Pages. See `DEPLOY.md` for the full setup guide.
